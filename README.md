# IPL Data Analysis Dashboard (2008–2025)

## 📊 Project Overview
This project is an interactive IPL dashboard built using Power BI.  
It allows users to analyze team and player performance across seasons from 2008 to 2025.

## 🚀 Features
- Season-wise filtering
- Orange Cap & Purple Cap analysis
- Top 4s and 6s hitters
- Team performance points table

## 📈 Key Insights
- Teams with consistent win ratios are more likely to reach finals
- Aggressive batting (4s & 6s) plays a crucial role in match outcomes
- Balanced teams perform better across seasons

## 🛠 Tools Used
- Power BI
- DAX
- Data Cleaning & Transformation

## 📌 How to Use
1. Download the `.pbix` file  
2. Open in Power BI Desktop  
3. Use slicers to explore different seasons
